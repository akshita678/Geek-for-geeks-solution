## 🚀 Getting Started

If you want to run any of the solutions locally on your machine, follow these steps:

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to a specific problem folder:**
   ```bash
   cd Basic/Leap_Year
   ```
3. **Compile and run the C++ file:**
   ```bash
   g++ solution.cpp -o solution
   ./solution
   ```
